# Marker-driven 꿀팁 카드 정책

`꿀팁 시작`과 `꿀팁 끝`의 명시적 쌍만 카드 구간이다. 음성인식이 자주 만드는 띄어쓰기(`꿀 팁 시작`), 조사(`꿀팁을 시작`), 어미(`꿀팁 시작하겠습니다`, `꿀팁 끝입니다`)도 marker로 인정하고, 어미를 포함한 marker 어절 전체를 하단 자막에서 지운다. `꿀팁 끝까지`는 일반 발화이므로 marker가 아니다. 일반적인 `꿀팁` 언급도 marker가 아니다. 중첩·고아·종료 누락·빈 구간은 카드로 렌더링하지 않고 review에 기록한다.

카드 제안은 현재 Codex가 만들며 1~5개 항목, 항목당 32자 이하, 실제 source cue ID 필수다. 원문에 없는 숫자·날짜·금액·URL·이메일·영문 식별자·고유명사는 추가하지 않는다. 불확실하면 `decision=review`로 둔다. 모든 항목은 결정적 validator 통과 후에만 렌더링한다. 최종 보고에는 카드별 구간 시각과 항목 수를 적고, review로 빠진 구간이 있으면 이유와 함께 알린다.
